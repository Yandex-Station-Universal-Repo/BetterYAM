# `alice.play(path)`

Проигрывает LED pattern из файла пакета.

- **Permission:** `led`
- **Аргумент:** относительный путь к pattern-файлу внутри пакета.
- **Результат:** завершается после pattern; ошибка чтения, формата или backend
  передаётся Lua.
- **Отмена:** остановка пакета отменяет playback.
- **Доступность Mini:** да, если LED backend доступен.

```lua
alice.play("patterns/pulse.json")
```

Путь проверяется на traversal-компоненты; абсолютные пути и `..` запрещены.
