# `alice.exec(program, args)`

Запускает исполняемый файл из каталога установленного пакета.

- **Permission:** `exec`
- **Аргументы:** относительный путь к программе и массив строк аргументов.
- **Результат:** stdout как строка; stderr и exit status отдельно не возвращаются.
- **Ограничения:** путь проверяется, запуск запрещён, если администратор
  отключил выполнение binary plugins.

```lua
local output = alice.exec("bin/helper", { "--version" })
```

Выдавайте permission только доверенным пакетам.
