# `alice.bluetooth.power(on)`

Запрашивает включение или выключение Bluetooth.

- **Permission:** `bluetooth`
- **Аргумент:** boolean.
- **Результат:** `nil` при успехе; системная ошибка или причина отказа
  передаётся Lua.
- **Доступность Mini:** только при наличии power script и остановленных
  `quasar_launcher2` и `maind`.

```lua
alice.bluetooth.power(true)
```

На Mini команда использует vendor script, который выключает радио и
перезапускает `bsa_server`. Цикл выключения/включения проверен при остановленных
`quasar_launcher2` и `maind`; после проверки радио было включено, а
`bsa_server` работал. Проверка ограничений производится при каждом вызове.
Не вызывайте ради проверки на работающей колонке: изменение состояния может
нарушить её работу.
