# `alice.wifi.setup(on)`

Включает или выключает локальную точку доступа для настройки Wi-Fi.

- **Permission:** `wifi`
- **Аргумент:** boolean.
- **Результат:** состояние запроса; ошибки setup передаются Lua.
- **Доступность Mini:** зависит от `wifi.ap` capability и конфигурации daemon.
- **Внимание:** включение точки доступа меняет сетевое состояние устройства.

```lua
alice.wifi.setup(true)
```
