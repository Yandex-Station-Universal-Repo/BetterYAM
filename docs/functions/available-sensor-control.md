# `alice.sensors.control.is_available()`

Проверяет поддержку изменяемых настроек датчиков.

- **Permission:** `sensors.control`
- **Результат:** boolean без изменения настроек.
- **Доступность:** проверяйте capability этой операции в
  `device.capabilities`; отсутствие capability означает, что операция
  недоступна.
