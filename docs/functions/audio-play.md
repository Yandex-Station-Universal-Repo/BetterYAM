# `alice.audio.play(path)`

Воспроизводит аудиофайл из файлов пакета.

- **Permission:** `audio`
- **Аргумент:** относительный путь к файлу внутри пакета.
- **Формат:** PCM WAV, mono или stereo, 8–192 kHz; не более 64 MiB и
  600 секунд.
- **Результат:** `nil` при успешном завершении; ошибка проверки файла или
  `aplay` передаётся Lua.
- **Отмена:** остановка пакета завершает `aplay` сигналом `SIGTERM` и ждёт до
  5 секунд, затем убивает процесс: `SIGKILL` посреди записи может оставить
  общий ALSA dmix в нерабочем состоянии.

```lua
alice.audio.play("sounds/notify.wav")
```

Тестовый звук может прервать штатное аудио колонки; тестируйте только когда это
приемлемо.
