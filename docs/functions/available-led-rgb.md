# `alice.led.ring.rgb.is_available()`

Проверяет поддержку RGB frame для LED ring (`led.ring.rgb`).

- **Permission:** `led`
- **Результат:** boolean без аппаратного вызова.
- **Доступность:** проверяйте capability этой операции в
  `device.capabilities`; отсутствие capability означает, что операция
  недоступна.
