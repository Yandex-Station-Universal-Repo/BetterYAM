# `alice.clock.off()`

Выключает поддерживаемые сегменты часов. Если часами управляет прошивка,
adapter может вместо этого вернуть ей дисплей, см.
[матрицу поддержки устройств](../DEVICE_SUPPORT.md).

- **Permission:** `clock`
- **Аргументы:** нет.
- **Результат:** `nil` при успехе.

```lua
alice.clock.off()
```
