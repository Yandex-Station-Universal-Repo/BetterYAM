# `alice.sleep(ms)`

Приостанавливает Lua-пакет с периодической проверкой отмены.

- **Permission:** не требуется.
- **Аргумент:** длительность в миллисекундах, `0..60000`.
- **Результат:** `nil` после паузы; если пакет остановлен, возвращается ошибка
  `plugin stopped`.

```lua
while true do
    -- Выполнить работу.
    alice.sleep(250)
end
```

Используйте вместо busy loop, чтобы длительные пакеты оставались отзывчивыми
при остановке.
