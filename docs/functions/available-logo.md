# `alice.logo.is_available()`

Проверяет RGB capability, используемую совместимыми logo aliases.

- **Permission:** `led`
- **Результат:** boolean без изменения LED состояния.
- **Доступность:** проверяйте capability этой операции в
  `device.capabilities`; отсутствие capability означает, что операция
  недоступна.
